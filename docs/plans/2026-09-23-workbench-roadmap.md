Goal: close real Electron workflow gaps while making full-scope completion auditable in GitHub.
Spec: current user request, UI_DESIGN_CONTRACT, unchanged master/index and current native APIs.
Execution: inline continuation; preserve all reference/provenance/source-project boundaries.

1. Snapshot/branch and verify current source. Keep old checkpoints and no public model calls.
2. Pure-Python roadmap model/render/check: every inherited ID plus DevFleet/gov requirements,
   manual evidence-backed stage and estimate, weighted aggregate, native percentage vs historical
   reference claims separated. Generate GitHub Markdown/SVG progress, section tables and all rows.
   Test coverage/duplicate IDs/math/nonexistent evidence/stale outputs/invalid done/ETA semantics.
3. Add bounded multi-buffer native editing (up to12 open files), shared document instances, dirty
   markers, per-buffer versions, close/discard safety and response correlation. Test first with real
   Backend fixtures; never clear another file's edits on a delayed read/save or view switch.

   security defaults; prove keyboard/view/state flows and no eager browser/editor loads.
5. Evidence/metric maintenance required in every AI entrypoint, build/package verification, optional
   local hooks (only install if explicitly requested), and PR template. Check mode fails stale metrics
   or unmapped source work; no hidden network or docs generation during normal app runtime.
6. Native Release/Debug, tooling tests, reference gate and screenshots; update exact per-item stages,
   tests, estimates and structured changelog; source publish plus GitHub roadmap issue/comment.
