# Real Windows multi-terminal fixture

Captured from the running native Qt application, not Electron or a mockup. Two isolated cmd shells
had different environment variables. One was stopped; the other remained interactive. The selected
screen uses a test prompt and generic workspace display text to avoid publishing private paths.
Live status badges are transient process-state projections, not completed-task assertions.
No paid provider, DevFleet connection or third-party artwork is present.
